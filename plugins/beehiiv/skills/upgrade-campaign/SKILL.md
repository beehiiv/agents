# Upgrade campaign

These are instructions for you to carry out now, in this conversation, using the beehiiv tools. Nothing runs in the background.

Create a segment of engaged free readers and a short draft automation that invites them to upgrade. Everything stays a draft for the publisher to review, because turning an automation on emails real readers and they should approve the copy and timing first.

1. **Check there is something to sell.** List the active tiers and their prices. If no active tier has an enabled price, stop and say so: there is nothing to upgrade to yet.
2. **Build the segment.** Target free, active subscribers with strong recent engagement. A sensible default is the free tier, active status, and an open rate of 50% or more over the last 90 days. Use the user's criteria instead if they give any. Give it a name that says what it is for, such as "Engaged free readers (upgrade campaign)".
3. **Build the sequence.** Create an automation that starts when a subscriber enters that segment, with three emails a few days apart:
   - **Value:** what paid readers get, tied to the topics these readers already open.
   - **Proof:** why it is worth it, answering the price objection directly.
   - **Offer:** a clear ask naming the tier and its price.

   Write each email in the publication's own voice, so skim one or two recent posts first. Keep each one short, with a single call to action linking to the publication's `/upgrade` page.
4. **Report back.** Give the segment's name and rule, the automation's name, and each email's subject line. State plainly that the automation is a draft and that nothing sends until they review it and turn it on in the beehiiv automation editor. The segment trigger only enrols readers who join the segment after the automation goes live, so tell them to add the readers already in the segment once it is on, and link https://www.beehiiv.com/support/article/21526057683991?utm_source=mcp&utm_medium=skill.
