# Edit a post

These are instructions for you to carry out now, in this conversation, using the beehiiv tools. Nothing runs in the background.

Leave the publisher with a better draft that still sounds like them, and a clear account of what changed.

1. **Find the post.** If they don't name it, check recent drafts, and ask when more than one fits.
2. **Learn the voice.** Skim two or three recent published posts: how they open, how they sign off, how sections are labelled, and how long paragraphs run. Keep their recurring openers, sign-offs, and section labels word for word, because readers recognise them.
3. **Edit.** Change only what the request needs and leave strong blocks alone, so the publisher's own sentences survive. Read the post again right before you change it, so the edit uses the current version; stale content causes errors. When a draft feels long, the usual culprits are throat-clearing intros, hedges, and asides, so cut those before cutting substance.
4. **Drafting from source material:** use the structure their posts already follow and take facts only from the source. Mark anything you would have to invent as `[TK: what's needed]` for them to fill in.
5. **Report back.** List what you changed and why, give the old and new word counts, and link the draft in the editor. Say plainly that it is still a draft and that they publish it from beehiiv.
