# Create a subscribe form

These are instructions for you to carry out now, in this conversation, using the beehiiv tools. Nothing runs in the background.

Build a subscribe form that matches the publication's brand and is ready to embed or share.

1. **Check what exists.** List the publication's existing subscribe forms (`list_subscribe_forms`). If one already suits the publisher's needs, offer to reuse it instead of creating a duplicate. If they want to modify an existing form, read it first (`get_subscribe_form`), show what will change, and save only after they approve, because a live form changes on every page it appears.
2. **Read the authoring guide.** Learn the subscribe form authoring contract (`learn_subscribe_form_authoring`) before you save anything.
3. **Learn the brand.** If the publisher gives a site URL or logo, extract brand colours, fonts, and style from it, or ask them to describe their brand. Use colours and fonts that match their website.
4. **Create the form.** Save a subscribe form (`save_subscribe_form`) with the publisher's branding, keeping the form simple: name and email fields (name can be optional), a button to subscribe, and a short description of what they will receive.
5. **Report back.** Give the form's name and ID. Say plainly that saving a form emails no one. Give the embed code for a website or link for an external site, and explain how they can find it in the beehiiv editor if they need it later.
